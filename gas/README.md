# 作答回收設定（約 10 分鐘，只需做一次）

1. 用**學校帳號**新增一份 Google 試算表，命名為「理化課程站作答紀錄」。學生作答屬於學生資料，放在學校帳號比較符合規範。
2. 在試算表中點選「擴充功能 → Apps Script」，刪掉預設內容，貼上本資料夾的 `Code.gs`，然後存檔。
3. 點右上角「部署 → 新增部署作業」，類型選「網頁應用程式」，設定如下：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（學生不必登入就能送出）
4. 授權後會得到一個 `https://script.google.com/macros/s/…/exec` 網址。把它填進 `data/site.json` 的 `submitUrl`。
5. 回到試算表重新整理，選單會出現「理化課程站 → 更新統計」。
   - 「題目統計」：每一題的第一次作答答對率。
   - 「迷思統計」：各個錯誤想法被選了幾次，以及分布在哪些班。
6. （選用）在 Apps Script 的「觸發條件」中，設定 `buildSummary` 每天自動執行一次。

**注意**

- 修改 `Code.gs` 之後，要用「管理部署作業 → 編輯 → 新版本」重新部署，網址不會變。如果改成「新增部署作業」，網址會變，就要更新 `site.json`。
- 網址是公開的，任何人都可能送入假資料。程式會檢查班級（3 位數字）、座號（1～40）和題號格式，但無法完全防止惡意輸入。統計結果出現異常時，先檢查「作答紀錄」表。
- 這裡只記錄班級和座號，不記錄姓名。之後如果要把資料用在研究上，必須另外取得家長同意。
